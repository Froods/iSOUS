Detailed Description

Low-level I2C (TWI) driver til ATmega2560.

Abstraherer start, stop, write og read operationer på TWI-bussen.

◆ recoverbus()

void I2C::recoverbus ( )

Forsøger at befri en fastlåst I2C bus.

Deaktiverer TWI-hardwaren og klocker manuelt op til 9 gange på SCL for at frigøre en slave der holder SDA lav. Afslutter med en manuel stop condition og genaktiverer TWI.

◆ stop()

void I2C::stop ( )

Sender stop condition og frigør bussen.

Venter på at TWSTO-bit cleares. Hvis SDA stadig holdes lav af en slave efter stop, udføres manuel bus-recovery med SCL-pulsering.
