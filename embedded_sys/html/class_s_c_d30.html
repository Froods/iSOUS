Detailed Description

Håndterer kommunikation med SCD30 CO2 sensoren.

Klassen opdaterer sine interne attributter (CO2 og temperatur) når readData() kaldes. Værdierne hentes efterfølgende via getters.

◆ readData()

SCD30_Status SCD30::readData ( )

Poller sensor for data-ready og læser CO2 + temperatur.

Venter i op til ~5 sekunder (50 forsøg á 100 ms) på at sensoren melder data klar. Validerer alle CRC-checksums før data gemmes.

Returns
SCD30_OK ved succes, SCD30_TIMEOUT hvis sensoren ikke svarer, SCD30_CRC_ERROR ved checksum-fejl, SCD30_BUS_ERROR ved I2C-fejl.
