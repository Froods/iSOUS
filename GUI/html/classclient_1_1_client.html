Detailed Description

Håndterer pakning, afsendelse og læsning af UART-kommandoer.

Client indkapsler pyserial og udstiller en metode pr. GUI-kommando eller sensor request. Sender kommandopakker på 4 bytes: kommando, parameter 1, parameter 2 og STOPBYTE. Sensor og state læsninger forventer seks-byte svar fra embedded.
