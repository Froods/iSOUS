Detailed Description

GUI-sider, UART-kommunikation, tilstandsopdatering og logging.

GUI ejer tkinter-hovedvinduet, opretter sideobjekterne, kommunikerer med embedded-controlleren gennem Client.py og opdaterer realtidsdata.
